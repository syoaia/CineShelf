# CineShelf 🎬

A sleek, responsive web application designed for movie lovers to log, manage, and organize their personal cinematic watchlist and diary. Built with a modern dark-mode aesthetic.

## Features
* **Multi-Page Layout:** Seamlessly navigate between the home dashboard (`index.html`), viewing logs (`diary.html`), and entry submission forms (`form.html`).
* **Responsive Navigation:** Features a sticky header equipped with custom branding and flexible layout alignments.
* **Modern Design System:** Styled using Tailwind CSS, featuring a deep dark background (`zinc-900`) contrasted against vibrant emerald highlights (`emerald-300`).

## Tech Stack
* **Markup:** HTML5
* **Styling:** Tailwind CSS (via Play CDN)
* **Logic:** Vanilla JavaScript (`app.js`)
